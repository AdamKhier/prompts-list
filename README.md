# Prompt Templates — Build, Research & Automation

Six reusable prompt templates for shipping software with AI assistance: CLI tools, stats comparison, deep research, task management, CSV reporting, and project outlining.

## Contents

| File | Use it to |
| --- | --- |
| `01-build-cli-tool.md` | Scaffold a CLI tool from spec to tested binary |
| `02-build-stats-comparison.md` | Compare stats / benchmarks across runs |
| `03-deep-research.md` | Run a structured deep-research pass on a topic |
| `04-task-maker-and-manager.md` | Break work into tracked tasks and drive them |
| `05-csv-report-generator.md` | Turn raw data into a clean CSV report |
| `06-project-outline-manager.md` | Outline a project and keep scope under control |

## How to use

1. Pick the template matching your job.
2. Copy it into your agent / chat session.
3. Fill in the bracketed inputs at the top, then run.

Each file is self-contained Markdown — no dependencies, no build step.
